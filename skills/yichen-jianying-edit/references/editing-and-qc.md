# 剪辑判断与音频质检

## 删留

- DELETE：同一信息的重说、没有完成的半句、明显口误、独立犹豫音、无信息量的连续前缀。
- KEEP：支撑论点的演示、承接、限定语，以及听起来短但语义必要的词。
- CHECK：删掉会改变结论、数字口径不明、接句后可能断意、声音边界拿不准。向用户展示具体位置与影响，不能只问“这段删吗”。

先完成句段层面的取舍，再清气口。不要为了字数短删掉正常限定词，造成“比较高性价比”只剩后半个音节。选中的删除区间与被保护的有效发音不能重叠。

## 切口

ASR 对短词的起止可能偏几十到几百毫秒。给每个保留词留必要的发音边界，但不要把相邻已删词的起音留回来。RMS 的低能量点只能帮助选切点；不要把“低于某 dB”直接当作呼吸标签。

必要时记录时间戳修正：原时间、修正时间、相关词、波形/试听或复转写证据。保留完整的“好”，去掉后面废句的“它”；去掉“嗯”的尾音，同时保护接下来的“我”。

长句跨多个视频物理片段时，字幕按保留的语义短句组织，不要求一段视频对应一条字幕。单屏尽量一至两行；英文产品名会占不同宽度，需要原生画面检查。字幕避开脸、界面按钮和重要数据。

## 复查顺序

1. 全片源稿：重复、残句、逻辑跳跃与 CHECK 项。
2. 首版剪后 WAV：完整复转写一次，核对信息是否保留、是否残留重说或长空白。
3. 有具体问题才修改对应边界，并检查短窗口；新版文件使用新 hash，不能覆盖旧文件后误用旧缓存。
4. 剪映最终草稿：原生播放、保存、冷启动、现场结构回读。

`render-audio` 使用与草稿相同的保留区间、速度和目标长度，只导出音频，不生成视频。ffmpeg 的变速实现与剪映可能不同，因此它证明文字/时间映射和候选剪口，不能替代剪映真实听感检查。

静音检测报告只列候选，建议关注超过 180–250ms 的间隔，阈值随素材调整。词内停顿、英文拼读的间隔不应机械删除。没有静音段不等于完全没有呼吸声；没有解码错误也不等于剪辑质量通过。

ASR 拼错 Aisa、Vibe Coding、Skill、Similarweb、GEO、KOL 等名称时，用画面和上下文校正字幕，保留原声。识别器偶发重复与真正重口要区分，不要为了让转写文本“完美”而无休止重跑、压缩词尾。

## 停止条件

没有未解决的明确语义或剪口问题、字幕映射完整、原生草稿通过保存和冷启动，即可交付。只有新改动、新失败或明确未解疑点才增加检查。不能声称已经人耳全片试听、没有任何气口或完成导出，除非本次确有相应证据。

最终交付强调草稿状态；转写记录、SRT 与删留方案按任务需要保留，不用为了质检默认生成 MP4。
