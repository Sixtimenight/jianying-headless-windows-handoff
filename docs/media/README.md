# IG 真实案例演示媒体

本目录展示约 50 秒的 IG / Hypit 工程交接案例，媒体均来自实际项目。
首页使用图片对照。已收录的压缩视频作为可下载附件保留，不依赖 README 内嵌播放器。
以下四份演示衍生文件不附带原工程、39 份素材库、账号信息或官方程序库。

| 文件 | 内容与处理 |
| --- | --- |
| [Hypit 预览](hypit-original-preview.mp4) | 原 Hypit 成片的网页压缩版；不是剪映输出 |
| [剪映预览](jianying-import-preview.mp4) | 从同一归档转换出的多轨草稿，经剪映 11.5.0 原生导出后的网页压缩版 |
| [Hypit 画面](hypit-original-frames.png) | 原成片 1、8、17、28、37、48 秒画面的排列，从左到右、从上到下 |
| [剪映画面](jianying-import-frames.png) | 剪映原生输出的对应时间画面；不掩盖转换差异 |

原生剪映输出为 1080×1920、30 fps、1507 帧、50.233332 秒，完整解码通过。
两份网页视频缩为 540×960，H.264/AAC，保留全部 1507 帧和音轨；FFmpeg 压缩**仅用于网页演示衍生件**，
不能把该压缩步骤宣传为剪映原生导出过程。PNG 为 270×480 的六帧排列，不是界面截图。
视频去掉源元数据；未把本机路径、用户草稿文件或素材包作为展示附件。

原 Hypit 成片 SHA-256：`e2ff922d459a172680c96102ee38f4e5ae8ce1b400dd118b2aa56fb886c0dd06`。
该哈希与导入所用 Hypit Build 的最终视频归档记录一致。
剪映原生输出 SHA-256：`b545155bca0e58ccd72ef17e38239a921ecea2b0f995410497d50fd7c9958ffb`。
四份公开文件的精确 SHA 和大小固定在 `tools/check_package.py` 的 `PUBLIC_MEDIA`；不放开其他媒体扩展名。

本例是可编辑素材和基础时间线的交接，不是视觉无损转换。文字样式、裁切以及个别补充画面的显示时机有差异，
例如两份 37 秒画面的补充内容不同；不可据此宣称逐帧相同。详见[协作案例](../HYPIT-COLLABORATION.md)。
