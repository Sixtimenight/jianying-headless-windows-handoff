# 公开源码范围与分发边界

核心项目已获明确授权并设为公开；Skill 入口另收录到公开的
`mcncarl/yichen-skills` 总仓库。源码可见不等于官方集成许可、商业授权或跨设备
可用性认证。11.5.0 适配的本地验证不代表已经推送或发布新 Release。

## 收录

- 当前无界面草稿、时间线编辑、资源校验、关键帧、蒙版、转场、视觉效果和导出代码。
- 当前入口实际需要的草稿编解码、文件快照和目录锁定源码。
- 脱敏后的结构蓝图、资源身份/哈希目录、测试、独立 Skill、构建脚本和声明。
- 本次明确授权的 IG 案例演示：`docs/media/` 中两份视频预览和两份抽帧图，按精确路径、大小和 SHA 放行；来源与处理见该目录说明。

## 不收录

- 剪映安装包、官方动态库、内置字体、效果包、缓存音效和 GPU 编译缓存。
- 除上述四份已授权演示衍生件之外的真实视频、音频、用户草稿、原生账号资料、bookmark、Cookie、Token、密钥或带签名 URL。
- 历史实验输出、原始截图/日志、旧版本已登记在线音效的专用变更流程。
- 已编译的本项目 codec；使用者从这里的源码在本机重建，输出仍必须满足原有固定哈希。

旧资料只从此次发布范围排除，原始目录仍保留；不会为了发布而删除开发历史或上游声明。

## 开源与授权

代码许可证、剪映用户协议、素材许可、账号权益是不同层面的约束。
原创部分采用根目录 `LICENSE` 的个人学习和非商业使用条款，商业用途须取得
作者明确书面授权。第三方内容保留各自原许可；`licenses/` 内保留的文本不等于
把剪映及其资源授予同样的许可，不应把本预览称为 MIT / Apache-2.0 的整包开源项目。

后续推送、新建公开目标或 GitHub Release 按本次请求和实际授权执行；历史公开
授权不自动批准新的发布动作。总仓库只收录本 Skill 的说明、调用入口与口播
辅助脚本，不收录核心引擎代码或官方资源。不同机器的安装验收仍未完成。
